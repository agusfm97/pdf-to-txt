    Pertanyaan yang sering diajukan

    Apakah file saya diunggah ke server?

    Tidak. Seluruh proses ekstraksi teks berjalan di browser Anda menggunakan JavaScript. File tidak pernah meninggalkan perangkat, sehingga aman untuk dokumen pribadi maupun rahasia.

    Mengapa hasil teks kosong untuk sebagian PDF?

    PDF hasil pindaian (scan) berisi gambar, bukan teks. Untuk mengambil teksnya dibutuhkan OCR. Konverter ini memproses teks digital, jadi PDF scan perlu di-OCR terlebih dahulu.

    Apakah ada batas jumlah file atau halaman?

    Tidak ada batas dari sisi server karena tidak ada server yang terlibat. Kinerja bergantung pada perangkat Anda. File di atas 100 MB tetap bisa diproses, hanya saja lebih lambat.

    Apakah PDF yang dilindungi kata sandi didukung?

    Ya, Anda akan diminta memasukkan kata sandi saat file tersebut dikonversi.

    Apakah ini gratis?

    Gratis sepenuhnya dan tanpa registrasi. Proyek ini bersifat open source dan dapat Anda jalankan sendiri.

    Dibuat dengan PDF.js — berjalan sepenuhnya di browser Anda.
